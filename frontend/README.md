# EraRide Flutter App

## Setup
```bash
flutter pub get
flutter run
```

## Default API
Update `lib/core/constants.dart` for Android emulator/iOS/device.

## Included MVP Screens
- Auth (email login + OTP)
- Role selection
- Driver dashboard (create/manage rides)
- Rider dashboard (search/book/cancel)
- Teacher dashboard (complaints)
- Admin dashboard (driver approvals/suspensions)
- Chat room (WebSocket)
- Profile + wallet
